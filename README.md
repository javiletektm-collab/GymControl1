# GymControl Android

Primera aplicación Android de demostración para controlar socios, accesos, rutinas y membresías de un gimnasio.

## Método fácil, sin Android Studio

Lee `INSTRUCCIONES_DESDE_EL_MOVIL.md`. El proyecto contiene un flujo de GitHub Actions que genera automáticamente una APK descargable.

## Funciones actuales

- Entrada como administrador o socio de demostración.
- Resumen básico del gimnasio.
- Listado de socios.
- Simulación de lector QR y entradas/salidas.
- Rutinas de entrenamiento.
- Planes y membresías.
- Guardado local del estado de acceso.

## Estado

Es un prototipo local. No contiene todavía una base de datos online, pagos reales, autenticación segura ni integración física con el torno.
